# competitive-analysis-report

一个给 AI Agent 用的**竞品分析报告技能（Skill）**：丢给它一个产品或产品品类，它自动完成「多源检索 → 清洗结构化 → 撰稿」三步，产出一篇 12 节、可直接用于职场汇报和微信公众号发布的竞品分析报告，并配一张电影感封面。

适配 ToB / ToC、工具、AI、软硬件、数字化服务等任意产品。

## 它能产出什么

- 固定 12 节：调研摘要 → 调研概述 → 赛道格局 → 头部拆解 → 多维横向对标 → 逐家 SWOT → 差异化缺口 → 风险 → 趋势预判 → 落地策略 → 全文总结 → 参考资料。
- 多竞品横向对比用表格；关键数据标注来源类型；不编造数字，不确定的标"待核实"。
- 公众号风格 Markdown：标题 + 封面图（无文字、电影质感）+ 正文 + 话题标签 + 统一署名。
- 可选：一条命令推送到微信公众号草稿箱。

## 怎么用

在支持 Skill / Agent 的环境（Claude Code、豆包等）里，把本目录放进你的技能目录，然后直接说：

> 用竞品分析技能，分析一下「在线思维导图工具」这个品类。

> 帮我对标「Notion AI」，做一份竞品分析报告，然后发到公众号。

输入一个**具体单品**就做定向对标；输入一个**产品品类**就做头部+梯队全景格局。

## 目录结构

```
competitive-analysis-report/
├── SKILL.md                    # 触发描述 + 工作流 + 归档/发布约定
└── references/
    └── report-template.md      # 三阶段流程、12 节目录、写作与署名规范
```

## 它帮你省掉的事

- 不用每次复制一大段提示词；
- 报告自动按统一模板归档、自动编号；
- 封面自动生成、自动转存；
- 一条命令上公众号草稿箱。
